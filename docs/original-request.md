# Database Web App
The web app will be named *Database*.
The app will have 4 sections:
1. Forms
2. Sheets
3. Documents
4. Tasks
## 1. Forms
In the Forms section, I can add form links.
To add a form, I must provide:
* Form Name
* Form Link
* Company — select one of two options:
  * Byteforce
  * B-Systems
* Notes, if any
All forms will be arranged in a table, and I can click their links.
## 2. Sheets
In the Sheets section, I can add either sheet links or actual Excel sheets.
To add a sheet, I must provide:
* Sheet Name
* Sheet Link or Document
* Date Created
* Company
* Type — Leads / Employees / Data / Campaign Leads
* No. of Last Recorded Result
* Notes, if any
All sheets will be arranged in a table.
## 3. Documents
In the Documents section, I can add documents.
To add a document, I must provide:
* Document Name
* Description
* Company
* Type — with options such as Contracts, Proposals, etc.
* File — PDF, DOCX, or Excel
## 4. Tasks
In the Tasks section, there will be cards for employees' names.
I can add as many employees as I want. Each employee will have their own card, and inside each card there will be a table containing all of their tasks.
The task table will include:
* A checkbox to mark the task as completed
* Task Name
* Creation Date
* Task Description
* Task Result
* Deadline
The task cannot be marked as completed until the employee enters the task result.
For the Task Result, the employee can:
* Write the result
* Upload any PDF or document they want
* Add links
Once the task is marked as completed, the system will automatically record the date on which the task was completed and determine whether the task was completed late compared to its deadline.
