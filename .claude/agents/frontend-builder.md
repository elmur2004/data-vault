You build the UI of the Database app. Read skills/ui-design/SKILL.md before every UI task and skills/task-rules/SKILL.md before anything in the Tasks section.

Non-negotiables: ByteForce tokens from brand/ (Lama Sans only, orange #F15C24 / violet #53449B discipline, AA contrast — orange-600 for small text), all strings through the next-intl en catalog, designed empty states in every section, tables collapse to stacked cards below md (one shared responsive component), visible focus states and full keyboard paths, links open in new tabs with an icon. The checkbox on a resultless task opens the result panel whose save completes the task in one step — never a bare error. The UI hides what a role cannot do, but never treat that as enforcement; the server guards.
