# Data model

Implements SPEC.md §5–§6 on **PostgreSQL + Prisma**. The schema below is the reference; keep `prisma/schema.prisma` aligned with it and update this file if the human approves a change.

## Reference schema

```prisma
enum Company        { BYTEFORCE  BSYSTEMS }
enum SheetType      { LEADS  EMPLOYEES  DATA  CAMPAIGN_LEADS }
enum SheetStorage   { LINK  FILE }
enum DocumentType   { CONTRACT  PROPOSAL  INVOICE  REPORT  PRESENTATION  BRAND_ASSET  LEGAL  HR  OTHER } // close via D-04
enum TaskStatus     { OPEN  COMPLETED }
enum AttachmentKind { FILE  LINK }
enum UserRole       { ADMIN  EMPLOYEE }
enum ScanStatus     { PENDING  CLEAN  REJECTED }

// Auth tables (user/session/account/verification) are generated by Better Auth's
// Prisma adapter — see skills/auth-roles. Extend its user model with `role UserRole`.
// Employee.userId references that user table; null until the invitation is used.

model Employee {
  id         String    @id @default(uuid())
  userId     String?   @unique
  fullName   String    @db.VarChar(120)
  email      String    @unique @db.VarChar(160)
  jobTitle   String?   @db.VarChar(120)
  company    Company?             // ByteForce, B-Systems, or null = both (§5.1)
  isActive   Boolean   @default(true)   // deactivate, never delete (BR-13)
  tasks      Task[]
  invitation Invitation?
  createdAt  DateTime  @default(now())
  updatedAt  DateTime  @updatedAt
}

model Invitation {
  id         String    @id @default(uuid())
  employeeId String    @unique
  employee   Employee  @relation(fields: [employeeId], references: [id])
  tokenHash  String    @unique          // store a hash, never the raw token
  expiresAt  DateTime                   // created_at + 7 days (§5.2)
  usedAt     DateTime?                  // single-use
  createdAt  DateTime  @default(now())
}

model Form {
  id         String   @id @default(uuid())
  name       String   @db.VarChar(160)
  url        String   @db.VarChar(2048) // http/https only (BR-01)
  company    Company
  notes      String?
  createdBy  String
  isArchived Boolean  @default(false)
  createdAt  DateTime @default(now())
  updatedAt  DateTime @updatedAt
}

model Sheet {
  id                  String       @id @default(uuid())
  name                String       @db.VarChar(160)
  storageMode         SheetStorage
  url                 String?      @db.VarChar(2048) // required iff LINK (BR-02, app-enforced)
  fileId              String?      @unique           // required iff FILE
  file                StoredFile?  @relation(fields: [fileId], references: [id])
  dateCreated         DateTime     @db.Date          // user-entered; distinct from createdAt (§6.3)
  company             Company
  type                SheetType
  lastRecordCount     Int?
  lastRecordCountAsOf DateTime?    @db.Date          // required when count entered manually (BR-03)
  notes               String?
  createdBy           String
  isArchived          Boolean      @default(false)
  createdAt           DateTime     @default(now())
  updatedAt           DateTime     @updatedAt
}

model Document {
  id          String       @id @default(uuid())
  name        String       @db.VarChar(160)
  description String?                      // optional per D-07
  company     Company
  type        DocumentType
  fileId      String       @unique
  file        StoredFile   @relation(fields: [fileId], references: [id])
  createdBy   String
  isArchived  Boolean      @default(false)
  createdAt   DateTime     @default(now())
  updatedAt   DateTime     @updatedAt
}

model Task {
  id          String       @id @default(uuid())
  employeeId  String
  employee    Employee     @relation(fields: [employeeId], references: [id])
  name        String       @db.VarChar(200)
  description String?
  company     Company?                     // per D-05
  deadline    DateTime     @db.Date        // date-only per D-06; see skills/task-rules
  status      TaskStatus   @default(OPEN)
  resultText  String?
  completedAt DateTime?                    // server-stamped (BR-06)
  wasLate     Boolean?                     // frozen at completion (BR-07)
  daysLate    Int?                         // frozen at completion
  attachments TaskAttachment[]
  createdBy   String
  isArchived  Boolean      @default(false)
  createdAt   DateTime     @default(now()) // the "Creation Date" column
  updatedAt   DateTime     @updatedAt

  @@index([employeeId, status, deadline])
}

model TaskAttachment {
  id      String         @id @default(uuid())
  taskId  String
  task    Task           @relation(fields: [taskId], references: [id])
  kind    AttachmentKind
  fileId  String?        @unique           // iff FILE
  file    StoredFile?    @relation(fields: [fileId], references: [id])
  url     String?        @db.VarChar(2048) // iff LINK
  label   String?        @db.VarChar(160)
  addedBy String
  createdAt DateTime     @default(now())
}

model StoredFile {
  id               String      @id @default(uuid())
  originalFilename String      @db.VarChar(255)  // sanitised copy for display
  storageKey       String      @unique @db.VarChar(512) // non-guessable, see skills/file-service
  mimeType         String      @db.VarChar(100)  // from content inspection, not extension (BR-04)
  sizeBytes        Int
  version          Int         @default(1)
  replacesId       String?     @unique           // previous version chain (FR-S06/FR-D06)
  replaces         StoredFile? @relation("versions", fields: [replacesId], references: [id])
  newer            StoredFile? @relation("versions")
  scanStatus       ScanStatus  @default(PENDING) // only CLEAN files are servable (§10.3)
  uploadedBy       String
  uploadedAt       DateTime    @default(now())
}

model ActivityLog {
  id         String   @id @default(uuid())
  actorId    String
  entityType String   @db.VarChar(40)   // "form" | "sheet" | "document" | "task" | "employee" | "file"
  entityId   String
  action     String   @db.VarChar(40)   // "create" | "update" | "archive" | "restore" | "complete" | "reopen" | "reassign" | "deactivate" | "replace_file"
  meta       Json?                      // e.g. previous values on reopen (§9.5)
  createdAt  DateTime @default(now())
}
```

## Modeling rules

- **Conditional requirements live in code, not the DB.** BR-02 (sheet: exactly one of url/file) and the attachment kind pairing are enforced in zod schemas **and** re-checked in server actions. Add a Postgres `CHECK` via raw migration SQL if you want belt-and-braces.
- **Never hard delete** (BR-11). Every listing query filters `isArchived: false` by default; build one shared helper so nobody forgets. Archive/restore go through a service that also writes the ActivityLog.
- **ActivityLog is append-only.** No update or delete path, ever. Write entries inside the same transaction as the change they record.
- **Versioning.** Replacing a file creates a new `StoredFile` with `version = old.version + 1` and `replacesId = old.id`, then repoints the owning row's `fileId` transactionally. Old versions stay retrievable to admins.
- **Dates.** `deadline`, `dateCreated`, `lastRecordCountAsOf` are `@db.Date` (calendar dates, no time). Everything else is `timestamptz` UTC. Formatting to Africa/Cairo happens only in the UI layer (BR-15).
- **Seed script** (`prisma/seed.ts`): one admin user (credentials printed once to the console, not stored in the repo), 2–3 employees, and a handful of records per module so every table and empty state can be exercised.
- Migrations: `npx prisma migrate dev --name <change>`. Never edit an applied migration; add a new one.
